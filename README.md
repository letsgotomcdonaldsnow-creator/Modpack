# Pokémon Alola Adventure

A **Minecraft 1.21.1 Fabric** modpack that turns Minecraft into a Pokémon Sun & Moon style game. It is built on
[Cobblemon](https://modrinth.com/mod/cobblemon) and set in **Generation 7's Alola region**: tropical islands and
volcanoes, Alolan forms, Z-Moves, the Island Challenge, Poké Ride, Poké Pelago, malasadas and island life. It
bundles about 110 hand-picked mods plus their libraries. See [MODS.md](MODS.md) for every file and version.

## Install

You need a launcher that can import Modrinth packs (`.mrpack`). Java 21 is required; the launchers below handle it.

1. Download the latest `Pokemon-Alola-Adventure-*.mrpack`. Get it from the
   [Releases](https://github.com/letsgotomcdonaldsnow-creator/Modpack/releases) page, or from the **modpack**
   artifact of the latest [Build modpack](https://github.com/letsgotomcdonaldsnow-creator/Modpack/actions) run.
2. Import it:
   - **Modrinth App:** *Library → Create → From file*.
   - **Prism Launcher:** *Add Instance → Import* and choose the file.
   - **ATLauncher:** *Instances → Import*.
3. Give the instance **6 to 8 GB of RAM**, then launch.

Tips:
- Shaders are bundled but start off. Turn them on in *Options → Video Settings → Shader Packs → Complementary Reimagined*.
- On a slower PC, open *Mod Menu → Distant Horizons* and turn off rendering. Lowering the render distance also helps.
- Press `L` for the Island Challenge tab.

## Alola spawns

The pack's own data mod ([`alola/`](alola)) copies Cobblemon's spawn entries for each Alola native and points
the copies at island habitats, at double weight:

- **Tropical islands and beaches:** Pikipek, Yungoos, Alolan Rattata and Meowth, Cutiefly, Crabrawler, Sandygast,
  Wimpod, Pyukumuku and Alolan Exeggutor.
- **Jungles:** Bounsweet, Fomantis, Morelull, Comfey, Dewpider, Stufful and Komala.
- **Volcanoes:** Salandit, Turtonator, Alolan Marowak, Alolan Geodude and Jangmo-o.
- **Warm seas:** Wishiwashi, Mareanie, Bruxish and Dhelmise.

Everything else in the Pokédex still spawns normally.

## Running a server

The pack lists which mods are client-only, so a server gets only what it needs:

```sh
python3 tools/modpack.py server --dir alola-server --accept-eula   # --accept-eula means you agree to the Minecraft EULA
cd alola-server && java -Xmx6G -jar fabric-server-launch.jar nogui
```

This downloads every server-side mod from Modrinth (checking hashes) and installs the Fabric server launcher. It also
adds a `server.properties` with `allow-flight=true`, which you need so flying Pokémon mounts don't get players kicked.
Tools such as `mrpack-install` can install the `.mrpack` directly too.

## Changing the pack

Everything is driven by [`modlist.toml`](modlist.toml):

```sh
python3 tools/modpack.py resolve      # modlist.toml -> modpack.lock.json (exact versions + hashes)
python3 tools/modpack.py validate     # check every fabric.mod.json dependency, client and server
python3 tools/modpack.py build        # -> dist/Pokemon-Alola-Adventure-<version>.mrpack
```

- **Cobblemon is pinned** (`pin = "1.7.3"`, `anchor = true`). The resolver picks, for every other mod, the newest
  version whose `fabric.mod.json` accepts that Cobblemon version, Minecraft 1.21.1 and the Fabric loader.
- Locked versions are reused until you run `resolve --upgrade`. You can also run the workflow manually with
  *upgrade* ticked.
- Every push runs [the CI workflow](.github/workflows/build.yml). It resolves the pack, commits the updated lockfile
  and [MODS.md](MODS.md), validates dependencies, builds the `.mrpack`, then boots a real server with every
  server-side mod and scans the log for problems. Pushing a `v*` tag publishes a release.
- The Alola content is generated by `tools/gen_alola_spawns.py` (spawns, from Cobblemon's own data) and
  `tools/gen_island_challenge.py` (advancements and rewards).
