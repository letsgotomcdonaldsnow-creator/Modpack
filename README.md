# Pokémon Alola Adventure

A **Minecraft 1.21.1 Fabric** modpack that turns Minecraft into Pokémon Sun & Moon. It is built on
[Cobblemon](https://modrinth.com/mod/cobblemon) and ships with its own **Alola Region world**: Melemele, Akala,
Ula'ula and Poni with their towns, routes, trials, Kahunas and the Pokémon League. About 135 hand-picked projects
(170 files with libraries) cover Alolan Pokémon, Z-Moves and the Island Challenge, plus a large set of decoration
mods. See [MODS.md](MODS.md) for every file and version.

Every change is tested in CI before the download is updated:
- a real dedicated server boots the full pack on the Alola world and checks the trainers spawned;
- a real client boots the pack and joins a world;
- a second client flies a camera through Alola and publishes in-game
  [screenshots](https://github.com/letsgotomcdonaldsnow-creator/Modpack/releases/tag/tour).

## The Alola Region world

Open **Alola Region** from the singleplayer list, or run it on a server (see below). The world is generated by
[`tools/worldgen`](tools/worldgen) and includes:

- **Four islands** with the game's landmarks: Mahalo Trail and Iki Town, Ten Carat Hill, Wela Volcano, Brooklet
  Hill, Lush Jungle, Haina Desert, Mount Lanakila, Vast Poni Canyon, Exeggutor Island, the four nectar meadows and
  Aether Paradise out at sea.
- **Towns in their game styles**: Hau'oli City's street grid, palm boulevard, fountain plaza, shops and beach; Iki
  Town's huts on stilts; Heahea, Paniola's western ranch town, Konikoni's red lanterns, Malie's Japanese-style
  streets and garden, rainy Tapu Village, walled Po Town and Seafolk Village's houseboats.
- **Every trial and grand trial** with its Captain or Kahuna: Ilima, Lana, Kiawe, Mallow, Sophocles, Acerola, Mina,
  Totem Kommo-o, Hala, Olivia, Nanu and Hapu, then the Elite Four and Kukui at the League, Team Skull and the Aether
  Foundation, and Red and Blue at the Battle Tree. Beating one grants its Island Challenge step.
- **Pokémon Centers** with a Nurse Joy who heals your team, PCs, a café and a Poké Mart counter.
- **Streets and nature**: asphalt roads with markings and sidewalks (Saro's Road Blocks), smoothed slopes
  (Terrain Slabs), tapering Dynamic Trees trunks, Wilder Wild palms with coconuts, hibiscus and wildflower meadows,
  coral reefs with anemones, cattail ponds and geysers on Wela Volcano.
- **Detailed buildings** from Macaw's roofs, windows, doors, lights and furniture, CobbleFurnies, PokeBlocks,
  Supplementaries awnings, Handcrafted, Another Furniture and Beautify, every house furnished inside.

## Playing together

The world is set up for multiplayer:

- **A named Waystone in every town** (inside each Pokémon Center and at the big landmarks). Visit one to unlock it,
  then travel between any you have found.
- **Towns are safe**: creepers and fire can't damage builds (`mobGriefing` and `doFireTick` are off), and you keep
  your items and Poké Balls when you faint (`keepInventory`). Half the players sleeping skips the night.
- **Parties and land claims** with [Open Parties and Claims](https://modrinth.com/mod/open-parties-and-claims):
  make a party with friends, claim a house or build your own and nobody else can break it (open its menu with the
  keybind listed under *Controls*).
- **Proximity voice chat** with Simple Voice Chat, and trainers everyone can battle.

## Install

You need a launcher that can import Modrinth packs (`.mrpack`). Java 21 is required; the launchers below handle it.

1. Download **[Pokemon-Alola-Adventure.mrpack](https://github.com/letsgotomcdonaldsnow-creator/Modpack/releases/download/latest/Pokemon-Alola-Adventure.mrpack)**
   from the [latest tested build](https://github.com/letsgotomcdonaldsnow-creator/Modpack/releases/tag/latest).
2. Import it:
   - **Modrinth App:** *Library → Create → From file*.
   - **Prism Launcher:** *Add Instance → Import* and choose the file.
   - **ATLauncher:** *Instances → Import*.
3. Give the instance **8 to 10 GB of RAM** (the pack does not start with 6 GB), then launch.

Tips:
- The Complementary Reimagined shader is on by default. On a slower PC turn it off in *Options → Video Settings →
  Shader Packs*, and turn off Distant Horizons rendering in *Mod Menu*.
- Press `L` for the Island Challenge tab.

## Alola spawns

The pack's own data mod ([`alola/`](alola)) copies Cobblemon's spawn entries for each Alola native and points
the copies at island habitats, at double weight:

- **Tropical islands and beaches:** Pikipek, Yungoos, Alolan Rattata and Meowth, Cutiefly, Crabrawler, Sandygast,
  Wimpod, Pyukumuku and Alolan Exeggutor.
- **Jungles:** Bounsweet, Fomantis, Morelull, Comfey, Dewpider, Stufful and Komala.
- **Volcanoes:** Salandit, Turtonator, Alolan Marowak, Alolan Geodude and Jangmo-o.
- **Warm seas:** Wishiwashi, Mareanie, Bruxish and Dhelmise.

## Running a server

The pack lists which mods are client-only, so a server gets only what it needs, and the server uses the Alola
Region world:

```sh
python3 tools/modpack.py server --dir alola-server --accept-eula   # --accept-eula means you agree to the Minecraft EULA
cd alola-server && java -Xmx8G -jar fabric-server-launch.jar nogui
```

This downloads every server-side mod from Modrinth (checking hashes), installs the Fabric server launcher, copies
the Alola world in as `Alola` and writes a `server.properties` with `allow-flight=true`, which you need so flying
Pokémon mounts don't get players kicked. On first start the world places its Nurses, Captains and Kahunas.

## Changing the pack

Everything is driven by [`modlist.toml`](modlist.toml):

```sh
python3 tools/modpack.py resolve      # modlist.toml -> modpack.lock.json (exact versions + hashes)
python3 tools/modpack.py validate     # check every fabric.mod.json dependency, client and server
python3 -m tools.worldgen.generate --save --check   # build the Alola Region world into build/world/Alola
python3 tools/modpack.py build        # -> dist/Pokemon-Alola-Adventure-<version>.mrpack
```

- **Cobblemon is pinned** (`pin = "1.7.3"`, `anchor = true`). The resolver picks, for every other mod, the newest
  version whose `fabric.mod.json` accepts that Cobblemon version, Minecraft 1.21.1 and the Fabric loader.
- The world generator only uses block states listed in `tools/worldgen/block_catalog.json`, which CI rebuilds from
  the vanilla block report and every mod jar; `--check` fails on anything else.
- `ALOLA_LAB=1` adds a test platform to the world with a labelled showroom of the decoration mods' blocks and
  sample buildings. CI uses it for the screenshot tour; it is never shipped.
- Every push runs [the CI workflow](.github/workflows/build.yml): resolve, validate, generate the world, build, boot
  a server on the world, boot a client, take the screenshot tour, and publish the tested pack to the
  [latest](https://github.com/letsgotomcdonaldsnow-creator/Modpack/releases/tag/latest) release.
